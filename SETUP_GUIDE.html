Ashi Portfolio — Project Setup Guide

Easy, step-by-step handover instructions for running this application locally

Non-Technical Edition

🌱 Welcome! What is this project?

This is a complete full-stack website consisting of an animated interactive 3D/WebGL portfolio and a secure Node.js backend server with an SQLite database and image management admin panel. Everything runs locally on your machine with just 1 tool required.

1

The Only Prerequisite: Install Node.js

Node.js allows your computer to run the web server. If you don't already have it installed:

  1. Visit the official website: https://nodejs.org
  2. Click on the big green button labeled LTS (Recommended for Most Users).
  3. Run the installer file and click Next > Next > Finish (default settings are perfect).
  4. To verify, open your terminal (Command Prompt or PowerShell on Windows, or Terminal on Mac) and type:
node -v
# Should display a version like: v20.x.x or v22.x.x
2

Preparing and Sending the Project Files

If you are packaging the folder to send to someone else, keep it lightweight:

  • Do NOT include heavy cache folders: If there is a node_modules/ folder inside server/, delete it before creating the .zip. The new user will regenerate it cleanly in Step 3.
  • Make sure you include: All website folders (assets/, scripts/, styles/, gallery/, server/, and index.html).
  • Unzip: The recipient should extract the zip file onto their computer (e.g. Desktop or Downloads).
3

Install & Start the Server (3 Easy Commands)

Open your terminal, navigate inside the project folder, and enter these commands:

# 1. Move into the backend server directory
cd server

# 2. Install the required server dependencies automatically
npm install

# 3. Start the application
npm start
💡 First time setup note: If a .env file is missing inside the server folder, simply duplicate .env.example and rename it to .env before running npm start.

When the terminal says:

Ashi server running at http://localhost:3000
Database initialized and connected.
4

Viewing the Website & Admin Panel

Keep the terminal window open (do not close it while using the site), and open your favorite browser:

Destination URL (Type in address bar) What It Is
Main Portfolio http://localhost:3000 The full interactive website with 3D canvas, intro, and project gallery.
Admin Panel http://localhost:3000/admin Upload artworks, manage projects, rearrange gallery, and edit bio.
Default Admin Credentials: Username is admin. (Configured in your server/.env file).

Quick Troubleshooting for Common Problems

Problem Cause & Solution
'node' or 'npm' is not recognized Node.js was installed while the terminal was open. Close the terminal completely and reopen it.
Error: Port 3000 is already in use Another software on your computer is using port 3000. Open server/.env, change PORT=3000 to PORT=3005, save, and restart.
Images appear blank Ensure the server/data/ and gallery/ folders were included when unzipping.
How do I stop the server? Press Ctrl + C in the terminal window to shut down the server.
